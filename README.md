# U.S. Airline Performance & Delay Analysis

## Project Overview

This project analyzes over 1 million U.S. domestic flight records from 2015 to identify trends in flight delays, cancellations, airline performance, and airport operations.

## Tools Used

* SQL
* Power BI
* Microsoft Excel

## Key KPIs

* Total Flights: 1.05M+
* Cancelled Flights: 40.5K
* Average Arrival Delay: 7.6 Minutes
* Average Departure Delay: 11.3 Minutes
* Cancellation Rate: 3.86%

## Dashboard Features

* Airline Performance Analysis
* Airport Performance Analysis
* Monthly Flight Trends
* Interactive Filters
* KPI Monitoring

## Key Insights

* Southwest Airlines operated the highest flight volume.
* Some airlines experienced significantly higher cancellation rates.
* Major airports handled substantially larger traffic volumes.
* Monthly flight activity showed clear demand variations.
